🖼️ Django Image Upload & Display System

This project is a Django-based web application that allows users to upload, store, and display images.

🚀 Features:

* Upload images using frontend form
* Store images in media folder
* Save image reference in database
* Display images dynamically on frontend
* File handling using Django

🛠️ Tech Stack:

* Python
* Django
* HTML
* SQLite

📌 Core Concept:

* File upload handling in Django
* Media files configuration (MEDIA_URL, MEDIA_ROOT)

📂 Use Case:
This project helps beginners understand how to manage file uploads and display media content in web applications.
